# Evaluation data note

The API-based evaluation used 238 findings labeled BUG and 136 labeled NO_BUG.
Its aggregate confusion matrix was TP = 174, FN = 64, FP = 24, and TN = 112.

The case-level result manifest was not retained. For this reason, the package
does not reproduce the reported recall and false-positive rate case by case.
The 710 labels used by the separate clustering study are included.
